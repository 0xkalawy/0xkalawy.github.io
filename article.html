This post looks at what happens when a frame starts navigation while another component still refers to the previous document.

The setup

The test uses two local origins and an iframe. One page starts the navigation. The other records each state change.

NOTE 01

The old document should stop receiving trusted data as soon as the navigation commits.

The assumption

A document begins a cross origin navigation while a second component still holds a reference to the old execution context. The test checks whether that reference remains trusted.

const oldOrigin = frame.contentWindow.origin;
frame.location = target;

await navigationStarted(frame);
assert(oldOrigin !== frame.contentWindow.origin);

Tracing the state

I logged navigation start, document replacement and origin checks separately. One cached decision remained after ownership changed.

The complete post will include reproduction steps, affected builds and the disclosure timeline.

Takeaways

  • Log each navigation state.
  • Record which object makes the security decision.
  • Check cached permissions after ownership changes.
